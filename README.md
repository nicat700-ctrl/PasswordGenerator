# Password Generator 🔐

A simple Python password generator that creates strong random passwords.

## Features

* Custom password length
* Optional numbers
* Optional special characters
* Random password generation

## Technologies

* Python

## How to Run

```bash
python3 main.py
```

## Example

```bash
Parol uzunluğu: 12
Rəqəm olsun? (y/n): y
Simvol olsun? (y/n): y

Parol: H#7kP!2mQ@9x
```
